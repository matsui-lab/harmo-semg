# 文書定義から時刻・記録・処理への接続 v025

## 今回できるようになったこと

v024のリポジトリ接続に、二つの限定的な意味解釈規則と、切り出し済み周期の診断処理を追加した。入口は引き続き `harmo harmonize-batch`。研究IDでの分岐や、新規の研究専用リーダー生成は行わない。ただし、任意の論文・MAT構造を理解する機能ではない。

### CSVの時刻単位

公開説明文が、センサー数と取得間隔を「N sensors read data every … ms/s」、対象を「This data is stored in a CSV file with the timestamp」と明示する場合に限り、CSVのセンサー列数と全行の時刻を照合する。秒・ミリ秒の候補を試し、明示された取得間隔と一意に整合する単位だけを読み取り設定へ渡す。

- 元の時刻を作り直したり、欠損サンプルを補完したりしない。
- 曖昧な記述、複数の取得間隔、時刻の不規則性、列数不一致では適用しない。
- `slno` 等の行番号は、全行が0または1からの連番であることを検査して信号から分離する。元ファイルには残す。
- 設定には原文・文書ハッシュ・波形ハッシュ・時刻列・照合行数・規則名を記録し、変換直前にも再検査する。
- 時刻単位と刻みが整合することは、装置時計の精度や取得方法の独立検証ではない。

### MAT内の筋・測定側・課題

既存の親メタデータ型MATレイアウトに対して、関連論文のデータ辞書が明示するフィールドを実際のMATへ結び付ける。

1. チャンネル名フィールドの説明と実フィールド名・ラベル一覧が一致するかを検査する。
2. EMG測定側の定義フィールドから左右を読む。力板上の足とは区別する。
3. 試行内の課題フィールドを読み、通常歩行・踵歩行・階段等を区別する。今回は厳密な `Walking` のみ通常歩行処理へ進める。
4. 同一ファイル・同一試行キーのMarker／Grfを関連ストリームとして表示する。時刻同期を確定したという意味ではない。

筋名は限定語彙の完全名を用いる。未登録の略語、競合する定義、未知の側、別レイアウトは保留。GRF・MarkerをEMG対象件数に混ぜず、対象EMGを選んでから記録数上限を適用する。

### 切り出し済み周期の診断処理

関連論文が、EMGが歩行周期の開始・終了間に切り出されていることを明示し、試行フィールドから基準となる足も読める場合には、別の登録手順 `source-delimited-stride-envelope/1` を使う。

処理は20–350 Hz帯域通過、125 ms RMS、101点への位相変換、周期内ピークによるスケーリング。元の一つの区間を使い、架空のフットスイッチや複数周期を生成しない。連続記録用の最小周期数条件を満たしたとは報告しない。

各曲線は1周期だけなので、記録内のばらつき推定はできない。基準となる足が異なる周期、および連続記録と切り出し済み記録は同じ比較群にまとめない。

前後サンプルがないため、反射・端値延長を仮定した感度試験を併記する。これは失われた実データの復元ではない。比較結果には `source-segment-boundary-sensitivity-unresolved` とピーク位置感度を付け、科学的承認は行わない。

## 利用方法

新規URLでの操作は [v024](AUTOMATIC_WORKFLOW_v024.md) と同じ。変換前に保留された古いsummaryだけを後段へ渡しても再変換はされないため、新しい取得・変換試行が必要になる。今回の再試験スクリプトは、保存済みファイルを照合して新しい出力先へ複製し、追加ダウンロードせずに再変換する。

```sh
PYTHONPATH=src python scripts/paper/verify_document_field_join_v001.py \
  --source-jobs paper/multi_repository_recheck_jobs_v002_2026.09.15-r2.json \
  --output /absolute/path/to/new-verification-output
```

上記は保存済みの開発試験を再現するスクリプトであり、一般利用者用の任意データ入力コマンドではない。一般の入口は `harmonize-batch`。旧成果物は上書きせず、新しい出力先を指定する。

実データの到達点と限界は [検証報告](../paper/results/document_field_join_v003_2026.09.15-r3/REPORT_ja_v001.md) を参照。
