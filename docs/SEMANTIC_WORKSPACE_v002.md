# 意味確認ワークスペース v002

実行・再評価のCLIは[前版の手順](SEMANTIC_WORKSPACE_v001.md)と同じ。画面の操作を次のように更新した。

1. 出力フォルダの `review.html` を開く。`src/harmo/semantic_workspace.html` はデータを含まないテンプレート。直接開いた場合は出力フォルダの `workspace.json` を読み込む。
2. 確認者名を一度入力する。
3. 表示された一つの問いについて、候補値、元チャンネル、メタデータ・資料の該当箇所を照合する。根拠資料の事前選択は推薦であり、確認済みを意味しない。必要なら資料を切り替え、根拠に含めるチェックを調整する。
4. 適用できる場合は「この記録として扱える」のチェックを付けて確認する。対象・採用値・根拠IDは記録へ自動転記され、文章入力は不要。
5. 値を修正する場合は「別の値に修正」を開き、値と修正理由を記入する。候補が一つに絞れない場合は自動採用しない。
6. 分からない場合は保留し、理由を選ぶ。推測で入力する必要はない。
7. 判断を保存し、既存の根拠検査・再評価へ渡す。画面だけでカタログや科学的な比較の可否は更新されない。

原文抜粋は文字列検索と表示整形であり、適用範囲の意味的検証ではない。筋名と課題はヘッダーのみでの確認を受理しない。全ての資料が不足する場合は手入力を要求して穴埋めせず、保留できる。
