# 歩行EMGの電気的イベント基準による診断的比較 v022

## v021から追加したこと

[v021](AUTOMATIC_WORKFLOW_v021.md) の部分取得・文書による属性設定に続き、取得済みの連続EMGと同側フットスイッチから、周期抽出、共通処理、位相曲線、記録間比較までを実行できるようにした。
研究IDによる分岐はなく、取得したカタログ・チャンネル属性・信号状態に基づく。ただし現在の実データ検証はTai Chi 2の同一参加者2記録に限られる。

これは**診断用の別経路**である。電圧状態の変化を踵接地と認定せず、既存の科学的利用判定・信頼属性を変更しない。出力を生成できても承認済みの研究間比較が得られた意味にはならない。

## 使用手順

1. v021のURL取得を実行し、出力された `automatic.summary.json` の実在パスを確認する。
2. 次のコマンドに渡す。既存の出力先は上書きしない。

```sh
python -m harmo.footswitch_timing \
  --summary /absolute/path/to/automatic.summary.json \
  --output /absolute/path/to/new-timing-diagnostic
```

3. `diagnostic.json` の記録別 `reasons`、採用・除外イベント、周期数を確認する。保留した理由を無視してパラメータを緩和しない。
4. `curves.csv` と `curve-*.npz` で中央値・四分位範囲と個別周期を確認する。`comparisons` は同一データセット・筋・側・電気的基準の記録間比較であり、参加者や介入条件を揃える解析デザインは自動作成しない。

## 入力条件と処理

- 文書の根拠からwalking、surface-emg、筋、左右が解決されていること。同側フットスイッチは属性または明示的なRT/LT等のチャンネル名で対応する。
- 単一の2〜4段階の離散フットスイッチ信号を扱う。4段階は加算的な電気状態と整合する場合だけ分解する。連続的な床反力、雑音を含む連続電圧、複数の同側フットスイッチはこの版では扱わない。
- 同一サンプリング時刻上で立ち上がりを検出し、前後の状態が20 ms以上、周期0.5〜3秒、記録端から0.5秒以上を採用条件とする。不採用の短い遷移をまたぐ周期も除外する。最低5周期。
- 全記録の平均を除き、20〜350 Hzの4次Butterworthを前後方向に適用、中心化125 ms RMSを計算する。各周期の最大値でスケールし、101点へ補間する。これは形状の比較用であり、振幅の生理学的正規化ではない。
- 同じ基準の曲線間で、位相を最適化せずに相関、RMSE、循環ピーク位相差を計算する。処理済みEMGでないという仮定が残り、既知の処理履歴としては登録しない。
- 原資料、波形、契約、処理コード、設定のハッシュを保存し、実行中に入力が変われば最終報告を生成しない。

数値条件を変更する場合は、`diagnostic.json` 内の `profile` 全体を別JSONファイルに保存し、`--protocol` で指定する。設定の一部だけのJSONや、`phase_reference` をheel-strikeに書き換えた設定は受け付けない。

## 実際の検証結果

[結果報告](../paper/results/footswitch_timing_v001_2026.09.15-r1/REPORT_ja_v001.md) に数値・図・再実行コマンドを保存した。
2記録から16曲線・8組の記録間比較を生成し、16曲線すべてが再実行で完全一致した。
電気的基準を変えると採用周期と曲線形状が変わり、RMS窓変更でも最大ピーク位置が不安定な曲線がある。

## 人が確認すること／まだ実装・実証できていないこと

1. 公開された機器・収録仕様等から、電気状態が踵／つま先のどちらを表すか、極性、適用する記録を確認する。現段階で波形の見た目だけから認定しない。
2. 元EMGの処理履歴、除外すべき記録、比較する参加者・条件を確認する。単に相関の高い基準や設定を選ばない。
3. 生理学的イベントの独立した正解ラベルを使い、検出時刻・欠落・誤検出を評価する。この版に正解ラベルはない。
4. 文書確認をイベント処理の承認済み契約へ接続する機構と、未知研究での外部検証が必要。現在の属性確認票へのconfirmだけでは、この診断経路を科学的な比較出力へ昇格できない。

今回の追加にLLMは使っていない。既存の候補生成機能は利用できるが、その意味的正解率・実際の人の確認時間の改善は未測定のままである。
