# 切り出し波形の境界処理と比較範囲 v026

## 変更点

切り出し済み周期用の手順を `source-delimited-stride-envelope/2` に更新した。通常の連続記録の処理は変更していない。旧結果は別の出力先に残し、v2での新しい実行と混ぜない。

### RMS端点補正

125 ms窓内に実在するサンプル数で二乗和を割る。欠けている前後区間をゼロとして振幅を低く見積もる処理を避ける。これは欠けた波形の復元ではなく、端点では推定に使える情報量が少ないことも併記する。

帯域通過フィルタの極の減衰（暫定基準0.001）から計算した余裕に、RMS半窓を加えた区間を境界の不確実領域とする。この基準は誤差の数学的保証や生理学的妥当性確認ではない。

### 複数ピークと比較出力

- `timing_features.peaks` に複数の局所ピーク、位相、高さ、境界領域かどうかを残す。
- 暫定条件は正規化波形のprominence 0.05、最小距離3%周期、高さの競合差0.05。今回の実験結果に合わせて閾値を最適化していない。
- 境界領域にある最大値、非一意な最大値、高さが近い複数候補では単一候補を保留する。
- 中央の明瞭な候補があっても、それを全周期最大値と保証しない。`single_peak_scope` は中央領域の暫定候補、`global_peak_status` は前後文脈不足による保留を示す。
- 切り出し済み周期の比較における `left_peak_percent`、`right_peak_percent`、`circular_peak_difference_percent` は `null` にする。従来の最大値計算は `unqualified_peak_diagnostics` に診断用として残す。
- 両波形で共通に使える中央領域の点数と形状RMSEを `supported_metrics` に出す。ここでは共通領域内で正規化し、境界の最大値による中央波形のスケーリング変化を避ける。全周期の同等性・振幅比較とは異なる。

対応ピークを近いものから自動で同一視したり、0–50%周期を無根拠に立脚相とみなしたりはしない。生理学的な活動相の対応には別の根拠が必要である。

## 処理方針

連続信号が使える場合は、その信号を処理してから区間を切り出す。部分取得を行う場合も前後の実波形を保持する。今回の条件では前後0.5秒を確保すると連続処理結果と数値的にほぼ一致したが、他のフィルタ・信号へ一律の保証を与える値ではない。

前後の実波形がない場合は、端点補正、複数ピーク保持、利用可能な中央領域の表示を行う。全周期最大ピークを確定したい用途では保留を維持する。反射・端値延長による感度試験は続けるが、それらを実データとして扱わない。
