Your projects

What can I open?

A portable .harmo project includes prepared recordings, source metadata and available literature. Imported projects start a fresh review; earlier human decisions are not transferred.

Your selected file is copied to the local service on this computer, not sent to a remote server. The demonstration uses generated signals, not research observations. This review interface does not download new repository URLs or include a local language model.

Use “Export” to create a portable project for another computer. Check data sharing and redistribution permissions before sharing it.

Saved on this computer

Closing a browser tab does not stop Harmo. Save your decisions before leaving a review. Use Quit here after processing has finished. Updates do not delete saved data.
